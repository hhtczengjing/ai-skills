# 中文文档润色

对用户提供的中文文本进行润色，不改动原意与语气。

## 步骤

1. 通读原文，标出语病、冗余、标点与术语不一致处。
2. 修正语法与标点（中文使用全角标点）。
3. 精简冗余表达，删除「的」「了」滥用。
4. 输出：先给修改后的全文，再用要点列出关键改动。

## 规则

- 保留作者口吻，不做事实性改动。
- 术语一旦选定，全文统一。
- 如原文有歧义，先向用户确认再改。
