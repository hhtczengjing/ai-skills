# 常见问题

## ❌ `需要 ffmpeg 来裁剪 / 转码，但未安装`

脚本需要 ffmpeg 来做尾部裁剪和 mp3 转码。安装：

```bash
brew install ffmpeg
```

装完后重新运行脚本即可。

## ❌ `语音 'XXX' 不存在`

Voice 名拼写错误，或系统没有该语音。运行：

```bash
say -v "?"
```

查看完整列表。带括号的增强语音需要在「系统设置 → 辅助功能 → 朗读内容 → 系统语音 → 自定义」里下载。

## ❌ `3 轮后仍仅 X 秒，未达目标 Y 秒`

文稿实在太短，自动扩稿也补不上来。常见原因：

- 目标时长 > 文稿实际可达时长（例如 30 分钟目标但只给了 200 字稿）
- 选了一个语速特别慢的 voice

解决：

1. **手动加内容**：在文稿末尾补段总结、例子或回顾
2. **换更快的 voice**：用 `--rate` 手动指定，或换 enhanced 语音
3. **减小目标时长**

## ⚠️ 最终时长差超过 2 秒

- **ffmpeg 帧边界**：mp3/m4a 是按帧编码的，`-t` 在帧边界上可能多几十毫秒，通常在容差内
- **再次裁剪**：可以再跑一次脚本（用已有 AIFF 作为输入），或在 ffmpeg 后手动 `-t` 一次

## ⚠️ 音频末尾听起来突然截断

`ffmpeg -t` 不会做淡出。如果在乎收尾自然：

```bash
ffmpeg -i out.m4a -af "afade=t=out:st=298:d=2" out-fade.m4a
```

（在最后 2 秒做淡出，避免硬切）

## 速度估计偏差大

如果 `--rate` 自动测速算出来的字数跟你预期差很多（比如短文测出 200 字/分但实际写稿时 300 字/分），有两个原因：

1. **基线样本太短**：当前默认 80 字，再长会更准
2. **文稿风格不同**：对话多、术语多、感叹号多都会拖慢节奏

手动指定：

```bash
python3 generate.py --text-file speech.txt --target-seconds 300 \
  --rate 280 --format m4a
```

## 想换语速但不换时长

`--rate` 改字/分钟数，时长会自动变化。如要保持时长不变，需要按比例缩放文稿。
